# Bloom Braid Builder

An AI-powered Streamlit app that turns uploaded flower photos into custom garland or bouquet arrangement images, complete with an automatic flower count and a downloadable PDF report.

## Features

- Upload up to 5 flower reference images (PNG/JPG)
- Choose arrangement type: **Garland** or **Bouquet**
- Garland shapes: U Shape, Straight, Heart Shape, Oval Shape
- Bouquet styles: Round Bouquet, Cascade Bouquet, Hand-tied Bouquet
- Optional green leaf filling between flowers
- AI-generated arrangement image via OpenAI's `gpt-image-1`
- Automatic per-flower count (via `gpt-4o`) after generation
- Download the result as PNG or a branded PDF report
- Companion "Bloom Shop" static page served alongside the app

## Requirements

- Python 3.9+
- An OpenAI API key with access to `gpt-image-1` and `gpt-4o`

## Setup

```bash
cd garland
python -m venv venv

# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
OPENAI_API_KEY=your-openai-api-key-here
```

## Running

```bash
streamlit run app.py
```

- Streamlit App: http://localhost:8501
- Bloom Shop Page: http://localhost:8502
